# NOVENTRA Academy

## وضعیت فعلی
این پوشه نمونه اولیه رابط کاربری آکادمی مستقل NOVENTRA است. فایل‌های HTML، CSS و JavaScript فعلاً نمای ظاهری و چند تعامل ساده مانند منوی موبایل و پنجره معرفی ورود را فراهم می‌کنند.

**هنوز قابلیت‌های زیر پیاده‌سازی نشده‌اند:**
- ثبت‌نام و ورود واقعی کاربران
- پایگاه داده و ذخیره اطلاعات
- نقش‌های مدیر، مدرس و هنرجو
- مدیریت دوره‌ها، درس‌ها و پیشرفت
- انجمن پرسش‌وپاسخ و بارگذاری فایل
- پرداخت و انتشار محتوای پولی

## مسیر توسعه ترکیبی
1. بازبینی و آزمایش رابط کاربری در موبایل و دسکتاپ
2. نهایی‌کردن ساختار مسیرهای آموزشی و صفحات داخلی
3. بررسی پروژه Firebase موجود و اتصال امن Authentication
4. طراحی ساختار Firestore و سطح دسترسی نقش‌ها
5. پیاده‌سازی دوره‌ها، انجمن و کتابخانه
6. آماده‌سازی نسخه وب نصب‌پذیر (PWA)
7. بررسی بسته‌بندی اپلیکیشن موبایل با Capacitor در مرحله بعد

## معماری و نکات امنیتی
- رابط کاربری: HTML، CSS و JavaScript سبک
- سرویس‌های سمت سرور: پس از بررسی تنظیمات پروژه Firebase انتخاب و متصل می‌شوند.
- هیچ کلید خصوصی، رمز عبور یا فایل تنظیمات محرمانه نباید در کد عمومی GitHub قرار بگیرد.
- PWA با اپلیکیشن بومی Android/iOS یکسان نیست؛ انتشار در فروشگاه‌ها مرحله جداگانه‌ای دارد.

## شیوه همکاری
در هر مرحله، تغییرات کد در همین شاخه مستقل انجام می‌شود تا شاخه اصلی وب‌سایت NOVENTRA دست‌نخورده بماند. پس از هر مرحله، کد و نتیجه برای بازبینی و تمرین توضیح داده می‌شود.
